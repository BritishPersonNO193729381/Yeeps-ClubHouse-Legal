# Yeeps-ClubHouse
This will be the REPO attached to my website... if you are here, well done. You are one of the users who gets to contrebute to a WONDERFUL project that will help the dev community out emmencely.

## What does this Website do?
The aim of the website is to give developers a platform to share their creations with others and, maybe, even monetise their tools and creations.

This will be able to add some economy to yeeps as a whole and will also encourage more developers to create tools for the game.

By creating this website, we will become the main collector of yeeps-based websites and will be able to use that to give players an experience OUTSIDE of the game that, generally, makes the game arguably better.

## Why do this?
Doing this could not only make the game some money in the long run but, also, foster a developer community that will be able to educate and make new community members.

It also has the chance to more thoroughly link both communities together as, developers and consumers have always had quite a historical gap in communication.

So, by providing this website, we will be able to create a bridge for this gap and allow users to connect more with developers in a constructive way.
